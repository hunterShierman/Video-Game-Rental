## For Dashboard Access (Developers)

You've been invited to the Supabase project!

### First Time Setup:
1. Check your email for Supabase invitation
2. Click "Accept invitation"
3. Create Supabase account (or sign in)
4. Project appears in your dashboard

### Access Dashboard:
**URL:** https://supabase.com/dashboard/project/xxxxxxxxxxxxx

### What You Can Do:
- **Table Editor** - View/add/edit game data
- **SQL Editor** - Run custom queries
- **Authentication** - View registered users
- **Database** - See table structure

### What You CANNOT Do:
- Change RLS policies (ask Hunter)
- Delete tables (ask Hunter)
- Change project settings
- Access billing

---

## Common Tasks

### Add a New Game:
1. Go to Table Editor
2. Click "games" table
3. Click "Insert row"
4. Fill in all required fields
5. Click "Save"

### View All Users:
1. Go to Authentication → Users
2. See all registered accounts

### Run a Query:
1. Go to SQL Editor
2. Click "New query"
3. Paste SQL
4. Click "Run"
